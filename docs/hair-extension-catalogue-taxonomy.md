# Hair Extension Catalogue Taxonomy

Purpose: give LHC a stable structure for turning shop-floor hair-extension observations into clean catalogue families, variants, and later sellable products.

This is a catalogue-building reference, not a customer guide.

## Core Principle

The product family matters more than the individual observed variant.

Once the correct family exists, variants can be added, removed, priced, barcoded, photographed, and activated later. The hard part is correctly placing each observed product under the right brand, product line, product type, and style/family.

Recommended hierarchy:

1. Brand
2. Grouping path / product line / sub-brand
3. Product type
4. Style / family
5. Variant axes
6. Sellable SKU

Example:

```text
Brand: Cherish
Grouping path: Cherish > Bulk
Product type: Crochet Braid
Style / family: Passion Twist
Main variant: 18 inch
Sub variant: Colour BG
Common variant: 1X, 2X, 3X only if it changes the sellable pack
```

## Product Type Controlled List

Use a short controlled product-type list. Do not let brand line names become product types.

### Braid / Braiding Hair

Loose synthetic or human hair used to create braids by hand.

Examples:

- Ultra Braid
- Pre-Stretched Braid
- Lagos Braid
- Jumbo Braid
- French Curl Braid
- Knotless French Curl Braid

Common clues:

- "Braid", "Braiding Hair", "Pre-Stretched"
- loose hair, no fixed loop, no weft track
- hot water set instructions

### Bulk Hair

Loose non-weft hair sold for creating twists, boho braids, human-hair blend braids, or adding curly pieces.

Examples:

- Water Wave Bulk
- Deep Bulk
- Afro Kinky Bulk
- Bohemian Bulk
- Brazilian Bulk

Common clues:

- "Bulk"
- no pre-loop
- not on a weft track
- often used for boho/goddess braids, twists, or crochet styling

### Crochet Braid

Pre-looped, latch-hook, ready-install hair. This can look like braids, twists, locs, curls, or bulk-style curls, but the product type is crochet if the sellable product is meant to be installed by crochet/latch hook.

Examples:

- Nu Soft Locs
- Butterfly Locs
- Passion Twist
- Spring Twist
- Marley Braid crochet
- Boho Locs
- Feather Crochet

Common clues:

- "Crochet", "Pre-loop", "Latch hook"
- loop/hook symbol on packaging
- already formed locs/twists/braids

### Weave / Weft Hair

Hair attached to a weft/track, usually sewn in, glued in, or used as weave-on hair.

Examples:

- European Weave
- Yaky Weave
- Body Wave Weave
- Deep Wave Weave
- Human Hair Weave
- Synthetic Weave

Common clues:

- "Weave", "Weft", "WVG", "Weave On"
- straight/wavy hair attached to a horizontal track

### Clip-in Extensions

Temporary hair extension pieces attached with clips.

Examples:

- 1 Weft Straight
- 3 Weft Beach Wave
- Clip-in Fringe
- Clip-in Hair Extension

Common clues:

- clip count, number of wefts, "clip-in", "one piece", "three piece"

### Ponytail

Hair piece designed to attach as a ponytail.

Examples:

- Drawstring Ponytail
- Wrap-around Ponytail
- Claw Clip Ponytail
- Instant Pony
- EZ Pony

Common clues:

- "pony", "ponytail", "drawstring", "wrap", "claw clip"

### Wig / Lace Wig

Full cap or lace-based head covering. Keep separate from extensions if the catalogue page includes wigs.

Subtypes:

- Full Wig
- Lace Front Wig
- Lace Part Wig
- Half Wig
- U-Part Wig
- Headband Wig
- Braided Lace Wig

### Closure / Frontal / Hair Piece

Use when the product is not a full wig and not a normal extension.

Subtypes:

- Closure
- Frontal
- Bang
- Bun
- Scrunchie
- Topper

### Salon Extension Methods

Keep these available for future, but do not force them into afro hair-extension intake unless the packaging clearly says so.

- Tape-in
- I-tip
- Nano ring
- Micro loop
- Keratin bond / fusion
- Halo

## Material Taxonomy

Material is usually an attribute, not a product type.

Use material fields or notes for:

- Synthetic Fibre
- Kanekalon
- Toyokalon
- Heat-resistant Synthetic Fibre
- Premium Fibre
- Human Hair Blend
- Human Hair
- Remy Human Hair
- Virgin Remy Human Hair
- Unprocessed Human Hair

Do not put material into common variant unless the same exact family is genuinely sold in multiple material options.

Bad common variant:

```text
100% Human Hair
Soft Human Hair Texture
Premium Fibre
Anti-itch
```

Good common variant:

```text
1X
2X
3X
4X
6X
3 Pack
7 Piece
```

Kanekalon reference: Kanekalon is a synthetic fiber used for braids, wigs, weaves, crochet and extensions; official Kanekalon material lines include modacrylic, futura, ADVANTAGE and Ultima fibers.

## Variant Taxonomy

### Main Variant

Usually the main physical dimension.

Preferred order:

1. Length
2. Pack size / mixed length pack
3. Weight
4. Piece count

Examples:

- 14 inch
- 18 inch
- 22 inch
- 46 inch
- 14/18/22 inch mixed pack
- 100g

### Sub Variant

Usually colour.

Keep colour exactly as printed:

- 1
- 1B
- 2
- 4
- 27
- 30
- 33
- 613
- T27
- T30
- T530
- T1B/30
- P1B/30
- OT30
- 99J
- BG

Do not normalise away slashes, prefixes, or letters unless the source clearly proves a typo.

### Common Variant

Only sellable shared pack/count traits.

Examples:

- 1X
- 2X
- 3X
- 4X
- 6X
- 1 Pack
- 3 Pack
- 7 Piece

### Feature / Notes

These are not variants:

- Pre-stretched
- Pre-looped
- Itch-free
- Lightweight
- Flame-retardant
- Heat-resistant
- Soft texture
- Human hair feel
- Tangle free
- Brushable
- Hot water set
- Premium fibre
- Natural look

If a feature is part of the actual family identity, place it in grouping path or style/family.

Example:

```text
X-Pression > Pre-Stretched
Style: Ultra Braid
```

## Brand-Wise Structure Notes

### X-Pression / Outre

X-Pression should be treated as the main customer-facing brand when the packaging is X-Pression. Outre can be a grouping path where the packaging/product source makes it clear, but not a separate customer-facing brand in LHC if the shelf/product is bought and recognised as X-Pression.

Suggested structure:

```text
X-Pression
  > Braids
    > Ultra Braid
    > Pre-Stretched 2X 46 inch
    > Pre-Stretched 3X 72 inch
    > Pre-Stretched 6X 52 inch
    > Pre-Stretched Ultraviolet
    > Lagos Braid
  > Crochet / Twisted Up
    > Springy Afro Twist
    > Swicy Afro Twist
    > Springy Bohemian Twist
    > Water Wave Fro Twist
  > Weave On
    > Active
```

Important source pattern:

- Feme lists X-Pression braids such as Pre-Stretched 3x 72, Pre-Stretched 6x 52, Ultraviolet, Lagos, Ultra Braid and Pre-Stretched 2x 46.
- Outre classifies products into Lace Wigs, Wigs, Weaves, Braids, and Hair Pieces, with braid subtypes including Pre-Stretched Braid, Crochet Braid (Pre-Loop), Braiding Hair, Bulk and Kids.

### Sensationnel

Sensationnel has many product lines. Keep the master brand Sensationnel, then use line/grouping path.

Suggested structure:

```text
Sensationnel
  > Premium Too
  > Premium Too Feather Crochet
  > Empire
  > Goddess Select
  > Premium Now
  > Premium Plus
  > Soft N Silky
```

Product types can include Crochet Braid, Bulk Hair, Weave, Braid, Ponytail, Wig.

Source pattern:

- Sensationnel product pages expose attributes like Material, Braid Type, Style, Length and Colors. Use those as catalogue fields, not just text in the title.

### Cherish

Cherish needs careful separation between line and product type.

Suggested structure:

```text
Cherish
  > Bulk
    > Passion Twist
    > Water Wave
    > Deep Twist
    > Bohemian
    > Brazilian
    > Afro Kinky
  > Boho
    > Boho Braid
    > Saniya Boho Braid
    > Mona Boho Braid
  > Handmade / Locs
    > Butterfly Locs
  > Junior
    > Butterfly Locs
    > Silky Locs
    > Water Bulk
  > French Curl
    > Spiral French Curl
```

Rules:

- "Cherish Bulk" is a grouping path, not automatically product type Bulk Hair.
- If the package is a ready crochet/loc/twist product, use product type Crochet Braid even if "Bulk" is in the line name.
- If it is loose curl hair for braiding/twist work, use Bulk Hair.

Shaba examples show Cherish pages where length options combine pack count and length, e.g. "3X PACK 14", with colour as a separate dropdown. Split these into main length and common pack count.

## Naming Rules

Family name:

```text
Brand + grouping path/line + style/family
```

Avoid putting every variant into the family name.

Good:

```text
Cherish Bulk Passion Twist
```

Bad:

```text
Cherish Bulk Passion Twist 18 inch Colour BG 1X
```

Sellable product name:

```text
Family name - main variant - sub variant - common variant
```

Example:

```text
Cherish Bulk Passion Twist - 18 inch - Colour BG
```

Receipt/POS name can be shorter if the family already implies length or pack size.

## Parsing Rules For LHC Intake Cleanup

1. If product type is `BOHO`, move it to grouping path and set product type to the real format.
2. If product type is `Cherish junior`, move it to grouping path and set product type to Crochet Braid, Bulk Hair, or Braid based on physical format.
3. If common variant contains material or feature text, move it to notes.
4. Normalize pack labels:
   - `3x`, `3X Pack`, `3X VALUE PACK`, `3X EAZI-PACK` -> common variant `3X`; extra words to notes/grouping if meaningful.
   - `2x`, `2X VALUE PACK` -> `2X`.
5. Keep colour exactly as observed unless a reliable source proves correction.
6. When length and pack count are combined, split them:
   - `3X PACK 14"` -> main `14 inch`, common `3X`.
   - `14/18/22"` -> main `14/18/22 inch mixed pack`, common if 3X appears.
7. If one photo confirms a family but not all colours, create the family and observed variant only. Do not activate unobserved colours as stocked.
8. If a source page lists many variants, use it to understand the catalogue, not to claim shop stock.
